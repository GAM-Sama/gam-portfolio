Make: Gestión Inteligente de Pedidos

Automatización · Análisis de ventas · Comunicación con clientes

Resumen del Proyecto

Gestión Inteligente de Pedidos y Análisis de Ventas con Make.com

Este proyecto implementa un sistema completo de automatización para una tienda online real (Jamones San Pancracio – elreydeljamon.eu). Incluye un flujo avanzado para gestionar pedidos individuales y enviar emails personalizados, así como un informe semanal de ventas con KPIs y gráficos generados automáticamente.

El sistema conecta PrestaShop con una base de datos en Google Sheets, APIs externas, Gmail y servicios de análisis, permitiendo centralizar información, reducir trabajo manual y mejorar la comunicación con clientes. Además, se incorporan módulos de IA para redactar emails y generar informes de forma contextual y profesional.

El proyecto está diseñado con un enfoque modular, optimizado y totalmente escalable. He seguido iterando sobre él más allá de la presentación del Máster para reforzar estabilidad y robustez.

Características principales

1. Gestión de pedidos

Procesamiento en tiempo real, estructuración de datos y almacenamiento automático en Google Sheets con separación en rutas paralelas.

2. Emails con IA

Diferenciación B2C/B2B, enriquecimiento de datos con Apollo.io y redacción automática personalizada con OpenAI.

3. Informe semanal

Ejecución automática los lunes con KPIs clave, generación de gráficos dinámicos y redacción completa con IA.

4. Arquitectura robusta

Diseño modular, manejo de errores, validaciones y estructura optimizada para escalabilidad futura.

Módulos principales

1. Gestión de pedidos

Procesamiento en tiempo real, estructuración de datos y almacenamiento automático en Google Sheets con separación en rutas paralelas.

2. Comunicación con clientes

Diferencia entre B2C y B2B, enriquecimiento de datos con Apollo.io y redacción automática de emails con IA.

3. Análisis de ventas

Informe semanal con KPIs clave, generación de gráficos dinámicos y redacción automática con IA.

4. Subflujo de gráficos

Módulo independiente para generación de gráficos reutilizable en otros flujos del sistema.

5. Manejo de errores

Sistema robusto de captura y registro de errores con rutas alternativas para garantizar la continuidad del servicio.

6. Escalabilidad

Arquitectura modular que permite añadir fácilmente nuevos informes, KPIs o canales de comunicación.
