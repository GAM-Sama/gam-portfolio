YugiDex

Escáner inteligente de cartas Yu-Gi-Oh! · IA · Automatización · Web App

Resumen del Proyecto

YugiDex es una plataforma completa para identificar, gestionar y consultar cartas de Yu-Gi-Oh!. Su funcionamiento combina una app móvil desarrollada en Flutter —encargada de capturar y procesar el código de la carta mediante OCR de Google ML Kit— con un sistema de automatización en n8n que consulta la API de Yugipedia y almacena la información en Supabase (PostgreSQL).

El ecosistema incluye también una aplicación web creada con Next.js y React, que actúa como CRM para visualizar, filtrar y gestionar la colección desde cualquier dispositivo. La arquitectura se despliega de forma modular: n8n en Google Cloud y la aplicación web alojada en Vercel, con GitHub como control de versiones.

Aunque ya es un MVP funcional tanto en móvil como en web, sigo desarrollando y optimizando activamente el proyecto, mejorando procesos, ampliando funciones y perfeccionando la experiencia de usuario para convertirlo en una herramienta cada vez más completa y eficiente.
